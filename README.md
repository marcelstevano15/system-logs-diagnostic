# 🐧 Linux Native Desktop Apps

Modern native Linux desktop applications built with Rust.

Designed with simplicity, clean integration, low resource usage, and native desktop experience in mind.

While the applications are primarily optimized for GNOME and Libadwaita environments, they are still intended to work properly across other Linux desktop environments such as KDE Plasma, XFCE, Cinnamon, MATE, and more.

---

## ✨ Philosophy

This project focuses on creating desktop applications that feel:

- Native to Linux
- Fast and lightweight
- Clean and minimal
- Responsive even on older hardware
- Easy to use without unnecessary complexity

The goal is not to create bloated "everything apps".

Instead, each application should do one job well while integrating naturally with the Linux desktop experience.

---

## 🖥️ Desktop Environment Support

### Primary Focus
- GNOME
- Libadwaita
- GTK4

### Also Compatible With
- KDE Plasma
- XFCE
- Cinnamon
- MATE
- LXQt
- Other modern Linux desktop environments

Applications are designed to follow Linux desktop standards as much as possible while still embracing modern GNOME technologies.

---

## ⚡ Performance Goals

Performance is a major priority for this project.

Applications are designed to:
- Start quickly
- Use minimal memory
- Avoid unnecessary background processes
- Remain smooth on older hardware
- Feel responsive even under heavy multitasking

Even low-end systems should still get a clean native experience.

---

## 🦀 Why Rust?

Rust provides:
- Excellent performance
- Strong memory safety
- Reliability
- Modern tooling
- Native Linux development ecosystem

This makes it a great choice for building stable and efficient desktop applications.
